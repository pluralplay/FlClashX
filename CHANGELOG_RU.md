# Список изменений

Русская версия [CHANGELOG.md](CHANGELOG.md), с теми же записями в том же порядке.

## v0.5.3 (2026-11-13)

**Новое**

- **профили** В меню активного профиля на вкладке «Профили» есть «Подробнее»: счётчики, подписка и внешние ресурсы
- **l10n** Установщик Windows предлагает китайский язык, а у README появился перевод на китайский (#153)

**Исправления**

- **заголовки** Виджеты, которые вы расставили сами, не сбрасываются при обновлении подписки, если панель не запрещает их редактировать
- **linux** TUN на Linux сообщает, что Helper отказался запускать ядро, вместо того чтобы молча не работать, а AUR-пакеты больше не ломают контрольную сумму ядра (#156)
- **профили** В добавленных правилах профиля снова можно выбрать его прокси-группы (#154)
- **обновления** «Скрыть» в напоминании об обновлении скрывает только эту версию, а прогресс загрузки показывается прямо в кнопке «Скачать»

## v0.5.2 (2026-11-13)

**Исправления**

- **профили** Windows снова отправляет тот же HWID, что и FlClashX 0.4, поэтому лимит устройств больше не считает его новым устройством

## v0.5.1 (2026-11-13)

**Новое**

- **дашборд** Широкий дашборд на десктопе и ТВ показывает карточки, которые выбирает flclashx-widgets, в их порядке, и его можно редактировать
- **релиз** Пре-релизы ставятся отдельным приложением FlClashX Pre и при первом запуске копируют профили стабильной версии
- **профили** Цепочки прокси (бета): группа через два или три звена, настраивается на странице расширения профиля
- **дашборд** Скрытый исходящий IP больше не показывается звёздочками, а убирается, и переключение сервера берёт на себя название сервера на дашборде; у «Скрыть IP» есть свой переключатель на странице «Тема»
- **обновления** Обновление с зеркала провайдера ставится, только если его подписал FlClashX, поэтому зеркало не может подсунуть другую сборку
- **обновления** Обновления можно получать с собственного зеркала провайдера, указанного в подписке
- **обновления** Обновления скачиваются внутри приложения, проверяются по контрольной сумме релиза и подписи и ставятся в одно касание
- **бэкап** Бэкапы теперь содержат цепочки прокси каждого профиля
- **прокси** Добавленные правила профиля теперь могут направлять трафик через его цепочки прокси

**Исправления**

- **заголовки** Если панель перестаёт передавать hideip или novibrate, IP снова виден, а вибрация снова включена
- **android** На Android TV «Назад» с дашборда не останавливает VPN, а встроенный Zashboard больше не уступает старому MetaCubeXD
- **профили** QR-код профиля снова читается из картинки на Windows и Linux
- **прокси** В пустом разделе цепочек прокси больше не две кнопки «Добавить»
- **прокси** Переключение или применение профиля во время его загрузки больше не падает с ошибкой disposed ref

## v0.5.0 (2026-11-12)

**Несовместимые изменения**

- **профили** Пользовательские переопределения (custom overwrites) удалены; пересоберите их как пользовательские профили
- **настройки** Переключатели «переопределить DNS / NTP» убраны; DNS, NTP, sniffer и TUN настраиваются по отдельным ключам, и выбранные ключи действуют для всех профилей
- **tun** Настройки TUN на десктопе берутся из профиля, пока вы не выберете их сами; уже изменённые значения сохраняются
- **настройки** Настройки, которые задаёт подписка, принадлежат провайдеру; каждую можно взять на себя и вернуть
- **настройки** TLS-сертификаты проверяются всегда; переключатель, отключавший проверку, убран

**Новое**

- **ядро** Основа — FlClash 0.9.2, ядро — mihomo v1.19.34
- **заголовки** Заголовки подписки: flclashx-view, widgets, settings, special, newdomain, имя и логотип сервиса, serverinfo, buyplan, buytraffic и background
- **заголовки** hideip скрывает внешний IP, а app.theme позволяет панели задать тему приложения
- **заголовки** flclashx-override работает на собственной группе GLOBAL профиля
- **профили** Уведомления об окончании подписки; кнопка продления появляется в свой день, не дожидаясь обновления
- **профили** Внешний контроллер и Zashboard из подписки
- **прокси** Описания групп и серверов; описание группы показывается вместо выбранного в ней узла
- **настройки** Аутентификация из подписки задаёт логин и пароль прокси
- **профили** Ссылки на приложение добавляют профиль без подтверждения и сообщают об этом
- **настройки** Каждая настройка, которую называет конфиг (порты, режим, TUN, стек, MTU, контроль перегрузки, маршруты, geo и другие), закреплена за провайдером: закрытый замок — настройка провайдера, открытый — ваша
- **настройки** Любую настройку провайдера можно взять на себя и вернуть обратно, по одной; настройки, которых нет в конфиге, остаются вашими
- **настройки** Настройки из заголовков панели применяются один раз за обновление подписки или смену профиля
- **настройки** strict — третий режим поиска процессов
- **интерфейс** Интерфейс в духе iOS: тянущиеся шторки поверх друг друга, контекстные меню и выбор свайпом, жест «назад» перетаскиванием, пристыкованный поиск и сортировка долгим нажатием
- **интерфейс** Боковая панель и плавающий док; кнопки панели приподнимаются при наведении
- **интерфейс** Стекло (Liquid Glass) в двух уровнях, по желанию: матовые карточки дашборда, шторки и группы настроек; если видеокарта не успевает, стекло упрощается насовсем, и подписка его больше не поднимает
- **тема** Переработанные цвета темы, более контрастная тёмная тема, обновлённая иконка приложения, новые значки, пустые состояния и страница темы
- **языки** Французский, испанский и корейский — всего семь языков, русский перевод вычитан заново
- **дашборд** Новый дашборд вокруг текущего выхода: больше карточек, качество IP кэшируется на 3 дня
- **дашборд** Расширенный вид на новых установках; карточку статуса и объявление можно перемещать
- **дашборд** Логотип и имя провайдера в одной строке, логотип сохраняется на диске
- **дашборд** Нажатие на задержку открывает выбор сервера; кнопка перезапуска ядра, теперь и на Android
- **дашборд** Проверка доступности сервисов через прокси: Госуслуги, Сбербанк, VK, Яндекс и Кинопоиск, а также риск исходящего IP без запросов через Cloudflare
- **прокси** Группы карточками, вкладки групп чипами
- **прокси** Поиск, режим, тест всех и «свернуть всё» в одной группе кнопок, остальное — в «Ещё»; все группы можно развернуть или свернуть сразу
- **прокси** Узлы с таймаутом можно скрыть, поиск работает в любом списке
- **прокси** Прокси можно добавить в локальные; таймаут теста задержки настраивается
- **прокси** Новый профиль открывается на первой группе
- **профили** Пользовательские профили, include-all в пользовательских группах
- **профили** QR-код профиля и передача профиля с телефона на ТВ
- **профили** Импорт share-ссылок, наборы правил .mrs и больше полей прокси
- **редактор** Перенос строк и сниппеты
- **конфиг** DNS, NTP, sniffer и TUN по отдельным ключам; DNS, Hosts и порты применяются без перезапуска; общие переопределения необязательны
- **конфиг** Журнал DNS-запросов; кэш DNS можно очистить вручную или при смене сети
- **просмотр** Таблицы соединений, запросов и DNS с сортировкой; недавние запросы и живые соединения на одной странице; хосты в punycode показываются в Unicode
- **ядро** mihomo v1.19.34: TLS-отпечатки Firefox 148 и Safari 26.3, Snell v6 и несколько пользователей у Shadowsocks-слушателя
- **ядро** Упавшее ядро на десктопе перезапускается само, не больше двух раз подряд, и называет причину
- **android** Нарастающая вибрация при запуске приложения; удержание кнопки старт/стоп 5 секунд переключает прокси под нарастающую вибрацию
- **android** Постоянные 120 Гц; ядро работает в отдельном процессе и перезапускается без перезапуска приложения
- **android** Уведомление VPN показывает имя сервиса или профиля, по желанию только с кнопкой «Стоп»
- **android** include-package и exclude-package из TUN применяются всегда и важнее контроля доступа; умный выбор российских приложений и полоса состояния в контроле доступа; маршруты TUN из подписки
- **android** Ярлыки лаунчера и запуск по требованию в один шаг; без Firebase-аналитики и сбора падений
- **android** Сегодняшними логами можно поделиться из настроек
- **android** Приложение объясняет, почему VPN не запустился, если в разрешении отказано, и подсказывает на Android 17 про разрешение «Устройства поблизости»
- **десктоп** Первое окно открывается в мобильном виде вверху экрана, поэтому его всегда можно сдвинуть на маленьком экране
- **трей** Цветные значки статуса, на macOS есть монохромный вариант; горячие клавиши трея, узлы и тест задержки
- **приложение** Логи в файл и сброс приложения; без пресетов под Китай; обновлены дисклеймер и «О программе»; README переписан, заголовки подписки описаны на flclashx.app
- **миграция** Профили и настройки FlClashX 0.4 переносятся на macOS
- **прокси** Размер карточки прокси «в одну строку», его можно задать и через proxies.card:oneline
- **настройки** Вибрацию можно выключить переключателем, а панель — флагом novibrate
- **интерфейс** Фоном панели может быть анимированный GIF или WebP; рекомендуем анимированный WebP — он в несколько раз меньше GIF. Анимация останавливается на первом кадре, если в системе убраны анимации или GPU не справляется

**Исправления**

- **прокси** Обновление подписки больше не переключает группы url-test и fallback на мёртвый первый узел
- **прокси** Узел, выбранный во время применения подписки, больше не теряется
- **прокси** Load-balance проверяется по своим узлам, а группы без URL — по тестовому URL приложения, без двойных пингов
- **профили** Профиль, выбранный во время запуска приложения, больше не игнорируется, а изменения, набранные во время сохранения, сохраняются
- **ядро** Долгие соединения сохраняют свой маршрут; трафик UDP-сессии, перешедшей на другой маршрут, сразу учитывается на новом
- **ядро** Rule-set или geo больше 128 МиБ, кривой файл .mrs или профиль с размноженными YAML-алиасами больше не выедают память и не вешают приложение
- **ядро** Обновление базы GeoIP или ASN больше не может уронить ядро
- **бэкап** Повреждённая или слишком большая резервная копия отклоняется, а не восстанавливается
- **android** Старт VPN из быстрых настроек во время запуска приложения больше не теряется, а открытие приложения не перезапускает работающий VPN
- **android** Старт, отменённый прямо перед запросом разрешения VPN, больше не подвешивает следующие
- **android** Стоп в исключённой Wi-Fi-сети не даёт VPN включиться после выхода из неё, а настройки VPN, изменённые перед выходом, применяются при следующем старте из быстрых настроек
- **android** На Android 7–9 правила по приложениям больше не применяют политику другого приложения к общему UDP-сокету
- **десктоп** Сужение окна больше не закрывает открытый редактор профиля и не теряет изменения
- **десктоп** Системный прокси, который выставил не FlClashX, не трогается; прокси снимается, пока ядро не работает, и убирается после упавшего или убитого запуска
- **tun** TUN на десктопе, который не удалось запустить, показывается и выключается, а не висит включённым
- **macos** TUN работает через копию ядра вне приложения, принадлежащую root, и больше не падает после ввода пароля
- **macos** Меню в строке меню переживает повторное открытие из Dock; выход из системы, перезагрузка и выключение больше не отменяются; автозапуск работает на macOS 12; группы в трее ограничены 100 узлами
- **linux** TUN без systemd работает через копию ядра для каждого пользователя и больше не блокирует других пользователей; AppImage снова запускается
- **windows** Helper и клиент полностью закрываются перед установкой, зависший системный прокси очищается
- **интерфейс** Много исправлений интерфейса, фокуса клавиатуры и пульта ТВ, а также сохранения данных при загрузках, бэкапах и обновлении заголовков
- **android** Любой APK для Android теперь ставится поверх любого прежнего, какой бы вариант ABI ни был у каждого
- **android** VPN следит за переходом с одной сети Wi-Fi на другую, когда сети исключены
- **linux** RPM и AppImage для Linux запускаются на рабочих столах без установленной библиотеки AppIndicator
- **windows** Установщик для Windows обновляет установку 0.4 на месте, а не ставит рядом
- **прокси** Скопированная переменная прокси на Windows работает при вставке в PowerShell
- **прокси** Остановка системного прокси на macOS больше не выключает автоматическую настройку прокси (PAC)
- **миграция** При обновлении с 0.4 сохраняется список правил, который заменял правила подписки
- **миграция** При обновлении с 0.4 выбранный скрипт продолжает работать
- **миграция** При обновлении с 0.4 сохраняются настройки, которые переключатели override защищали от подписки

**Производительность**

- **редактор** Большие файлы редактируются плавнее; скобка рядом с курсором и тысячи share-ссылок с одним именем больше не подвешивают редактор
- **правила** Quick Edit больше не замораживает приложение на очень длинных списках правил
- **android** Интерфейс плавнее, пока прокси под нагрузкой
